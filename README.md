# SmartDesk v0.1

Prima versione della dashboard locale per Samsung Galaxy Tab S9 FE.

## Avvio rapido

Apri `index.html` con un browser.

Questa versione contiene:
- orologio e data in tempo reale
- layout HOME
- card Weather
- Now Playing
- Network
- Laptop
- Calendar
- System Status

Le integrazioni reali verranno aggiunte nelle fasi successive.
